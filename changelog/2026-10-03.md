# Changelog - 2026-10-03

## JSON serialization (`Device` and subclasses)

- **New methods in [device.py](../src/smart_factory/devices/device.py):** added `get_description_dict()` and `get_measurement_dict()`, which return Python dictionaries.
  - `get_measurement_dict()` is abstract: it raises `NotImplementedError` and must be implemented by subclasses.
  - `get_json_description()` and `get_json_measurement()` now only apply `json.dumps()` to the corresponding dictionary.
- **[sensor.py](../src/smart_factory/devices/sensor.py) and [actuator.py](../src/smart_factory/devices/actuator.py):** they now only override `get_measurement_dict()`. Removed the unused `import json` and fixed the `Actuator` docstring, which said "Sensor Status".
- **[industrial_machine.py](../src/smart_factory/devices/industrial_machine.py), description:**
  - It now overrides `get_description_dict()` and `get_measurement_dict()`, composing the dictionaries of the nested devices.
  - Fixed a **double serialization bug** in `get_json_description()`: nested devices were output as escaped JSON strings instead of JSON objects.
  - Renamed the description keys: `switch_id` → `switch`, `energy_sensor_id` → `energy_sensor`, `accelerometer_sensor_id_list` → `accelerometer_sensor_list`. They now match the measurement keys.
- **[industrial_machine.py](../src/smart_factory/devices/industrial_machine.py), measurements and cleanup:**
  - Removed the `json.loads`/`json.dumps` round trips from `get_json_measurement()`.
  - Renamed the variable `accelerometer_description_list` to `accelerometer_measurement_list` in the measurement method.
  - Fixed docstrings and comments, and removed `import json`.

## Fixes in `IndustrialMachine` and `EnergySensor`

- **Accelerometer IDs:** they were created as `<machine>_switch_N` and are now `<machine>_accelerometer_N`.
- **[energy_sensor.py](../src/smart_factory/devices/energy_sensor.py):** the kWh value now always increases, by a random amount between 1 and 3 kWh at each reading. Before, it could decrease and go below zero.
- **`EnergySensor` comments:** replaced the "humidity" references copied from another sensor, and changed "Kilo-watt per hour" to "Kilowatt-hour".
